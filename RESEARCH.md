# Inspiration research

The managed Agent Village release borrows interaction patterns, not branding or copy.

Canva AI emphasizes starting from an idea, refining through conversation, keeping the user in control, using connected context, adapting outputs, and scheduling work later. Figma emphasizes a shared AI-native canvas where people and agents work with shared context and stay connected from design to shipping. An agent UX reference emphasizes plan visibility, a separate activity stream, proactive status, pause/override points, confidence signaling, and structured recovery instead of a black-box chat response.

Sources:

- https://www.canva.com/canva-ai/
- https://www.figma.com/
- https://fuselabcreative.com/ui-design-for-ai-agents/

Translated into this site: one task composer, Town and Station views, capability routing, a visible orchestration trail, structured deliverable cards, local history, and a server-only seam for future LLM/media connectors.
